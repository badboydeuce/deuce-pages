03 / SECURITY MODEL

Know what each control does.

Privacy comes from access control. Search directives and scanner filtering are supporting layers, not authentication.
ACCESS

Invite-only accounts

Public signup is unavailable. Links expire, are stored as hashes, can be revoked, and stop working after successful registration.

SESSION

Server-checked portal

The private portal HTML and its main assets are returned only after the server verifies an active session cookie.

DISCOVERY

No search ranking

Every response carries no-index directives. Private routes are also excluded in the crawler policy and no sitemap is published.

PREVIEW

Restricted rendering

Imported pages use constrained preview routes and short-lived access tickets instead of becoming general public files.

Important

A public guide can still be requested by scanners that ignore crawler rules. It contains no private account data, credentials, secrets, unpublished packages or portal content.

04 / QUICK ANSWERS

Frequently asked.

Can anyone create an account?+

No. Registration requires a valid administrator invitation issued for a specific email.

Does the invitation still work after signup?+

No. It becomes unusable immediately after the account is successfully created.

Is this guide indexed by search engines?+

No-index headers and page metadata are applied to the guide and the rest of the service.

Can a crawler enter the private portal?+

Not without a valid user session. The server checks access before sending portal HTML or its main assets.

Where should I report an access problem?+

Contact the administrator who issued your invitation. Do not share invitation links, passwords or session information.
